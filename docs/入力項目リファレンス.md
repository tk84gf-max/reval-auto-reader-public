# 入力項目リファレンス（reval_calc.js / prefill_reval.js 共通）

計算エンジンに渡す JSON の形と、標準値・計算式のまとめ。

## 実行方法

```
node scripts/reval_calc.js input.json      # 評価カルテを出す（末尾に ===JSON=== 区切りで機械可読な結果）
node scripts/prefill_reval.js input.json   # 物件専用の ReVal HTML を analysis/ に生成する
```

カレントディレクトリはこのフォルダ（`ReVal.html` がある場所）にしてください。

## 入力JSONの全項目

```json
{
  "property": {
    "name": "物件名",
    "price": 14300,          // 物件価格（万円）
    "grossYield": 8.83,      // 表面利回り（%）。満室年収しか無ければ 満室年収÷(価格×10000)×100
    "buildAge": 20,          // 築年数（年）。築年月から本日基準で計算。新築・未竣工は 0
    "struct": "rc",          // "wood"=木造22 / "steel_light"=軽量鉄骨3mm以下19 / "steel_med"=軽量鉄骨3〜4mm27 / "steel"=重量鉄骨4mm超34 / "rc"=RC47 / "src"=SRC47
    "floorArea": 693.66,     // 延床面積（㎡）
    "landArea": 358.07,      // 土地面積（㎡）。積算の土地に使う
    "rooms": 24,             // 戸数
    "address": "岐阜県〇〇市〇〇町"
  },
  "loan":    { "ltv":90, "costsRate":7, "loanTerm":"auto", "intRate":2.0, "repayType":"genri" },
  "revenue": { "effRate":80, "vacancyRate":5, "declineRate":1, "parkingUnit":0, "parkingCount":0, "parkingVacancy":5, "otherIncome":0 },
  "expense": { "mgmtRate":5.5, "bmUnit":200, "utilUnit":50, "buildUnit":760000, "insurRate":0.3, "taxRateProp":10, "repairRate":0.5, "restoreUnit":10000, "turnover":25, "adMonths":1, "otherCost":0 },
  "sekisan": { "routePrice":0, "correction":1.0, "multiplier":1.0, "landDirect":0, "buildDirect":0, "deteriGrade":"other" },
  "tax":     { "taxRate":20, "buildRatio":70 },
  "actual":  { "fullRentAnnual":null, "currentRentAnnual":null, "mgmt":null, "bm":null, "util":null, "insur":null, "tax":null, "repair":null, "restore":null, "ad":null, "other":null }
}
```

`property` 以外は省略できます。省略した項目には上の標準値が入ります。

`prefill_reval.js` は追加で次を受け付けます。
`"date":"YYYYMMDD"`（省略時は本日）／`"templatePath"`（省略時 `ReVal.html`）／`"outputPath"`（省略時 `analysis/<物件名>_<日付>_ReVal.html`）

## actual（レントロール・実費／任意）

レントロールやランニングコスト表から読み取った**実数（円/年）**。入っている項目だけ標準計算を上書きします。

- `fullRentAnnual` 満室時年間賃料 ／ `currentRentAnnual` 現況（実稼働）年間賃料
- 費用: `mgmt` 賃貸管理 ／ `bm` 建物管理 ／ `util` 共用水光熱 ／ `insur` 損害保険 ／ `tax` 公租公課（固都税）／ `repair` 修繕 ／ `restore` 原状回復 ／ `ad` 募集経費 ／ `other` その他
- `currentRentAnnual` には空室率を二重に掛けないでください（現況は実稼働の実額そのまま）
- 共用水光熱がテナント直契約なら `util` に 0 を入れます

## 標準セット（毎回聞かずにこの値を使う）

| 区分 | 項目 | 標準値 |
|---|---|---|
| 融資 | 融資割合 LTV | 90% |
| 融資 | 諸費用率 | 7% |
| 融資 | 金利 | 2.0% |
| 融資 | 返済方式 | 元利均等 |
| 融資 | 返済期間 | 自動算出（下記） |
| 収入 | 有効率 | 80%（全構造） |
| 収入 | 空室率 | 5% |
| 収入 | 賃料下落率 | 年1% |
| 費用 | 賃貸管理料 | 実効賃料の5.5% |
| 費用 | 建物管理費 | 200円/坪・月 |
| 費用 | 共用水光熱 | 50円/坪・月 |
| 費用 | 建築費坪単価 | 760,000円/坪 |
| 費用 | 災害保険 | 再調達価格の0.3%/年 |
| 費用 | 固都税 | 実効賃料の10% |
| 費用 | 修繕費 | 再調達価格の0.5%/年 |
| 費用 | 原状回復 | 10,000円/坪 |
| 費用 | 回転率 | 25%/年 |
| 費用 | 募集AD | 1か月 |
| 税金 | 税率 | 20% |
| 税金 | 建物割合 | 70% |

**返済期間の自動算出**: 残存耐用年数＝法定耐用年数−築年数。残存が10年未満なら10年、それ以外は残存年数と30年の短い方。

## 主要な計算式

- 満室時想定賃料 ＝ 価格×10000 × 表面利回り/100
- 実効賃料 ＝ 満室賃料 ×(1−空室率/100)
- 坪 ＝ ㎡ ÷ 3.305785、賃貸可能坪 ＝ 延床㎡ × 有効率/100 ÷ 3.305785
- 再調達価格 ＝ 建築費坪単価 × 延床坪
- 賃貸管理費 ＝ 実効賃料 × 管理料率/100
- 建物管理費 ＝ 延床坪 × 200 × 12 ／ 共用水光熱 ＝ 延床坪 × 50 × 12
- 災害保険 ＝ 再調達価格 × 0.3/100 ／ 修繕費 ＝ 再調達価格 × 0.5/100
- 固都税 ＝ 実効賃料 × 10/100（簡易式。固定資産税評価額があればそちらを優先）
- 原状回復費 ＝ 賃貸可能坪 ×(1−空室率/100) × 10,000 × 回転率/100
- 募集経費 ＝ 実効賃料/12 × AD月数 × 回転率/100
- NOI ＝ (実効賃料＋駐車場＋その他) − 支出合計
- 自己資金 ＝ 価格×(1−LTV/100) ＋ 価格×諸費用率/100
- 年間CF ＝ NOI − 年間返済
- CCR ＝ 年間CF ÷ 自己資金 ×100 ／ 返済比率 ＝ 年間返済 ÷ 実効賃料 ×100 ／ CF率 ＝ 年間CF ÷ 価格 ×100

## 積算評価

- 土地 ＝ 土地面積 × 路線価(万円/㎡)×10000 × 補正率 × 乗数（`landDirect`>0 ならそれを優先）
- 建物 ＝ 延床面積 × 210,000円/㎡（劣化対策等級3なら240,000円/㎡）× 残存率（1−築年÷法定耐用年数）
- 積算比率 ＝ 積算合計 ÷ 物件価格 ×100
- **路線価が資料に無ければ土地は未算定**。公示地価などから推定しないでください

## 格付け

| 指標 | A | B | C | D |
|---|---|---|---|---|
| CCR | 20%以上 | 15%以上 | 10%以上 | 10%未満 |
| 返済比率 | 50%以下 | 60%以下 | 65%以下 | 65%超 |
| CF率 | 2%以上 | 1.5%以上 | 1%以上 | 1%未満 |
| 積算比率 | 100%以上 | 80%以上 | 60%以上 | 60%未満 |

収入がゼロ（利回りも年収も不明）のときは、返済比率は D になります。
