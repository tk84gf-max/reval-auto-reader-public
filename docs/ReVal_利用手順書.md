ReVal 自動読み取り　利用手順書
不動産のマイソク（販売図面・物件概要書）を放り込むだけで、AIが数値を読み取り、収益指標・積算・税引後CF、さらに「想定／満室実数／現況実数」の3列比較まで一発で出すツールです。
お使いのパソコンに合わせて、どちらかの章だけを読んでください：
Windows の方 → 「Windows をお使いの方」（次のページ）
Mac の方 → 「Mac をお使いの方」
（料金・カスタム・注意は最後の「共通」にまとめています）
🪟 Windows をお使いの方
セットアップ手順
アプリをダウンロード
下のページを開き、緑の「Code」→「Download ZIP」。ZIPを右クリック →「すべて展開」で解凍。
　配布ページ：https://github.com/tk84gf-max/reval-auto-reader
Node.js を入れる
https://nodejs.org で「LTS」をダウンロード → インストーラは全部「次へ」でOK。
※すでに入っている人は飛ばしてOK。
APIキーを取得
https://console.anthropic.com にログイン →「Billing」でカード登録＋少額チャージ（$5で数百枚分）
「API Keys」→「Create Key」→ sk-ant-… の鍵をコピー
鍵を登録（初回だけ）
フォルダ内の「初回設定_APIキー.bat」をダブルクリック → メモ帳が開く → 鍵を貼って保存（Ctrl+S）。
※鍵はあなたのPC内だけに保存され、アプリのフォルダやネットには出ません。
起動する
「ReVal自動読み取りを起動.bat」をダブルクリック → 黒い画面が出て、数秒でブラウザが開きます（localhost:5178）。
※黒い画面は開いたままに。閉じると停止（落ちても自動再起動）。
使い方
画面上の枠にマイソク（PDF・画像）をドラッグ＆ドロップ。複数まとめてOK。スクショを Ctrl+V でも入ります
読み取った数字を確認（違えば直すと自動で再計算）。黄色は「AIが自信なし」の項目
カードにカルテ＋「想定／満室実数／現況実数」の3列比較＋ReValシミュレーターが出ます
「📎 詳細資料を追加」にレントロール／ランニングコスト表を入れると、満室実数・現況実数も算出
「物件価格」を動かすと、賃料は固定のまま表面利回りが変わる＝価格交渉のシミュレーション
入れた物件はカードで積み上がり、上にCCR順のランキングも出ます

🍎 Mac をお使いの方
セットアップ手順
アプリをダウンロード
下のページを開き、緑の「Code」→「Download ZIP」。ZIPをダブルクリックで解凍。
　配布ページ：https://github.com/tk84gf-max/reval-auto-reader
Node.js を入れる
https://nodejs.org で「LTS」をダウンロード → .pkg を開いて指示通りインストール。
※すでに入っている人は飛ばしてOK。
APIキーを取得
https://console.anthropic.com にログイン →「Billing」でカード登録＋少額チャージ（$5で数百枚分）
「API Keys」→「Create Key」→ sk-ant-… の鍵をコピー
鍵を登録（初回だけ）
フォルダ内の「初回設定_APIキー.command」を 右クリック →「開く」→（確認が出たら）もう一度「開く」→ テキストエディタが開く → 鍵を貼って保存（⌘+S）。
※初回だけ右クリック起動が必要（Macのセキュリティのため）。鍵はあなたのMac内だけに保存されます。
起動する
「ReVal自動読み取りを起動.command」を 右クリック →「開く」→（「開発元を確認できません」と出たら）もう一度「開く」。ターミナルが開き、数秒でブラウザが開きます（localhost:5178）。
※このターミナルは開いたままに。閉じると停止（落ちても自動再起動）。
※「開発元を確認できません」は右クリック→「開く」で通ります。それとは別に「権限がありません」と出たときだけ、ターミナルでこのフォルダに入り「chmod +x *.command」を実行してください。
使い方
画面上の枠にマイソク（PDF・画像）をドラッグ＆ドロップ。複数まとめてOK。スクショを ⌘+V でも入ります

カードにカルテ＋「想定／満室実数／現況実数」の3列比較＋ReValシミュレーターが出ます
「📎 詳細資料を追加」にレントロール／ランニングコスト表を入れると、満室実数・現況実数も算出
「物件価格」を動かすと、賃料は固定のまま表面利回りが変わる＝価格交渉のシミュレーション
入れた物件はカードで積み上がり、上にCCR順のランキングも出ます

共通（Windows・Mac とも）
料金について
AI読み取りは、登録したあなた自身のAPIキーで動くので費用はあなた負担です（1枚あたり数円程度）。手入力の電卓・計算機能だけなら費用はかかりません。
自分でカスタムしたい人へ
計算部分（ReVal.html）は1ファイルで完結。エディタで開いて標準費率を自由に変更できます
GitHubで「Fork」すれば自分専用版を持てます。本体更新を取り込むことも可能
ご注意
本ツールは投資判断の「補助」です。最終判断は必ずご自身の責任でお願いします。
